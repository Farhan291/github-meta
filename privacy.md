# Privacy Policy

GitHub Meta does not collect, store, or share personal information.

The app only:

- Reads public Reddit posts and comments to detect GitHub repository URLs.
- Fetches public repository metadata from the GitHub API.
- Posts a reply containing that public metadata.

No Reddit user information is stored.
No analytics or tracking are performed.
No data is sold or shared with third parties.

If you have questions, open an issue on the GitHub repository.
